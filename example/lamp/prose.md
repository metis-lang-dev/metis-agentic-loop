A desk lamp on the person's table. The person can switch it on or switch it off.
When it is on, the lamp is lit; when it is off, it is dark. It starts dark.
The lamp's own words for what it shows are `lit` and `dark`; the person's commands
arrive as `cmd_on` and `cmd_off`; its bulb has a wear sensor that reports `worn` (the
program declares it; no rule needs it yet). Switching on a lit lamp, or off a dark one,
changes nothing. When a switch is done the lamp says so (`done(on)`, `done(off)`).
